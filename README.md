# Fasting Focused Lifestyle

A React-based fasting journey tracker for 2026. Track your dry fasts, water fasts, and refeeds with detailed physiological information and meal plans.

## Features

- 📅 Interactive calendar view with year and month navigation
- 🔥 Track multiple fasting types: Prolonged Dry Fast, Water Fast, Short Dry Fast
- 🥗 Refeed day meal plans with protein targets
- 📊 Daily logging for weight, waist, energy, and mood
- 💾 LocalStorage persistence - your data stays in your browser
- 📱 Mobile responsive design

## Tech Stack

- React 18
- Vite
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```
